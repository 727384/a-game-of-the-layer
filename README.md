# a-game-of-the-layer
一个用C++做的增量游戏，使用了`loong-big-integer`中的`lbi.h`。 ~仅适用于Windows。~

特别鸣谢：Kimi（更新日志，代码审查）

**请在 1.4.6 【v1.4.6】版本及以前使用`lbi_fixed.h`而不是`lbi.h`。**

**1.4.10_pre1-3【1.4.X_pre1-3】、1.4.10【1.4.X】 及 1.4.10_1【1.4.X_1】 版本都有严重的bug，请使用 1.4.10_2_fixed【1.4.X_2_fixed】 进行编译。（1.4.10_2【1.4.X_2】 也有bug，但不如上述版本严重）**
